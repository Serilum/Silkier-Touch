<h2>Mod Description</h2>
<p style="text-align:center"><a href="https://serilum.com/" rel="nofollow"><img src="https://cdn.serilum.com/description/header/header.png" alt="" width="838" height="400"></a></p>
<p style="text-align:center"><a href="https://curseforge.com/members/serilum/projects" target="_blank" rel="nofollow"><img src="https://workflow.serilum.com/badges/svg/curseforge.svg" width="200"></a> <a href="https://modrinth.com/user/Serilum" target="_blank" rel="nofollow"><img src="https://workflow.serilum.com/badges/svg/modrinth.svg" width="200"></a> <a href="https://patreon.com/serilum" target="_blank" rel="nofollow"><img src="https://workflow.serilum.com/badges/svg/patreon.svg" width="200"></a> <a href="https://youtube.com/@serilum" target="_blank" rel="nofollow"><img src="https://workflow.serilum.com/badges/svg/youtube.svg" width="200"></a></p>
<p><strong><span style="font-size:24px">Requires the library mod&nbsp;<a style="font-size:24px" href="https://curseforge.com/minecraft/mc-mods/collective" target="_blank" rel="nofollow">Collective</a>.<br></span></strong></p>
<p><span style="font-size:18px">Silkier Touch extends the functionality of the silk touch enchantment. Each feature can be toggled on or off in the config. You'll be able to pick up items such as Spawners, Dragon Eggs, Cake (that hasn't been eaten), Infested Stone and more!<br><br>See the full feature list in the config settings below.<br></span><br><br><strong><span style="font-size:20px">Configurable:</span> <span style="color:#008000;font-size:14px"><a style="color:#008000" href="https://github.com/Serilum/.information/wiki/how-to-configure-mods" target="_blank" rel="nofollow">(&nbsp;how do I configure?&nbsp;)</a></span><br></strong><span style="font-size:12px"><strong>enableDragonEggDrop</strong>&nbsp;(default = true): Disables the dragon egg teleport functionality when using a silk touch pickaxe.</span><br><span style="font-size:12px"><strong>enableSpawnerDrop</strong>&nbsp;(default = true): Enables monster spawners to drop with silk touch. It keeps the mob data.</span><br><span style="font-size:12px"><strong>enableTrialSpawnerDrop</strong>&nbsp;(default = false): Lowers the trial spawner 'strength' to allow breaking it. Will be dropped with silk touch on a pickaxe. Changing this requires a reboot.</span><br><br><span style="font-size:12px"><strong>enableFullCakeDrop</strong>&nbsp;(default = true): Allows cakes that haven't been eaten from to drop with silk touch. Works with candle cakes as well.</span><br><br><span style="font-size:12px"><strong>enableBuddedAmethystDrop</strong>&nbsp;(default = true): Allows Budded Amethyst to drop when mined with silk touch.</span><br><span style="font-size:12px"><strong>enableFarmlandDrop</strong>&nbsp;(default = true): Allows Farmland to drop when harvested with silk touch.</span><br><span style="font-size:12px"><strong>enableTallGrassDrop</strong>&nbsp;(default = true): Allows Tall Grass to drop when harvested with silk touch.</span><br><span style="font-size:12px"><strong>enableSnowLayerDrop</strong>&nbsp;(default = true): Allows Snow Layers to drop when harvested with silk touch.</span><br><span style="font-size:12px"><strong>enableVinesDrop</strong>&nbsp;(default = true): Allows Vines to drop when harvested with silk touch.</span><br><br><span style="font-size:12px"><strong>enableInfestedStoneDrop</strong>&nbsp;(default = false): Allows Infested Stone to drop when mined with silk touch.</span><br><br><br><span style="font-size:36px"><strong>Some examples:</strong></span><br><span style="font-size:18px">All mined with the Silk Touch enchant:</span><br><br><span style="font-size:18px"><strong>Monster Spawners:<br></strong><em>Trial Spawners are disabled by default:</em></span></p>
